# VkusVill HTML Zakas Order 🛒

Автономный HTML5-селектор товаров ВкусВилл с прямым вызовом MCP API.

**Живой сайт:** [volgarevmaxim-bit.github.io/vkusvill-html-zakas-order/](https://volgarevmaxim-bit.github.io/vkusvill-html-zakas-order/) — бесплатный хостинг на GitHub Pages.

## Что это

Одна HTML-страница, которая позволяет:

1. Продиктовать заказ на естественном языке (распознавание речи происходит на клавиатуре смартфона) - продукты соберутся в корзину автоматически или выбрать продукты из списка (119 товаров в 12 категориях) вручную
3. Нажать «Собрать корзину» → генерируется прямая ссылка на корзину ВкусВилл
4. Уже на сейте ВкусВилл скорректировать количество и оплатить (возможность доставки по вашему адресу ВкусВилл проверяет сам)

Всё работает в браузере телефона или ПК. **Сервер не нужен** — селектор вызывает MCP API ВкусВилл напрямую из браузера.

## Возможности

### 🎯 Быстрый ввод
Введи `нарзан йогурт мандарин` в строку поиска — трёхэтапный JS-матчинг сам найдёт товары:

1. **Alias-матчер** — 106 алиасов из quick-order
2. **Substring-поиск** — по всем 119 названиям
3. **Word + bigram** — токены склеиваются для многословных названий

### 📱 PWA
- Установка на домашний экран (Android Chrome, iPhone Safari)
- Иконка 🛒
- **Офлайн-каталог** — Service Worker кэширует страницу, всё работает без интернета (кроме создания корзины — нужен MCP)

### 🗂️ Поиск
Введи `нарзан йогурт мандарин` — трёхэтапный JS-матчинг встроен прямо в страницу, все 119 товаров и 106 алиасов уже в коде. Никаких внешних файлов.

### 🎨 UI
- Тёмная тема, Google-style вёрстка (строка поиска по центру)
- Адаптивная вёрстка (max-width 600px)
- Копирование ссылки в буфер
- Enter → авто-выбор товара → сразу кнопка «Собрать»

## Локальный сервер (обход блокировки CORS на стороне ВкусВилла)

Qrator-WAF на `mcp.vkusvill.ru` отвечает **401 на preflight OPTIONS**, поэтому
статическая страница на GitHub Pages не может вызвать MCP напрямую:
браузер блокирует запрос (`Failed to fetch`), кнопка «Собрать корзину» пишет
«Нет связи с сервером». Обычный POST из curl при этом работает — ломается
именно preflight.

Рабочий вариант — отдавать страницу и `/mcp` с одного origin:

```
python proxy/local_proxy.py 8770        # http://127.0.0.1:8770/
python proxy/local_proxy.py 8770 --lan  # доступ с телефона в домашней сети
start-proxy.bat                         # то же + открыть браузер
```

Прокси на stdlib (без зависимостей), upstream — `https://mcp.vkusvill.ru/mcp`.
С GitHub Pages страница тоже пытается ходить напрямую и в локальный прокси,
но Chrome блокирует запросы с https-страницы на `http://127.0.0.1`
(mixed content), поэтому публичный URL без собственного https-прокси
(Cloudflare Worker / Vercel) работать не будет.
