# VkusVill HTML Zakas Order 🛒

Автономный HTML5-селектор товаров ВкусВилл с прямым вызовом MCP API и серверной частью на Flask.

**Живой сайт:** [vv.vedomir.ru/select/](https://vv.vedomir.ru/select/) — открытый доступ, без пароля.  
**Зеркало на GitHub Pages:** [volgarevmaxim-bit.github.io/vkusvill-html-zakas-order/](https://volgarevmaxim-bit.github.io/vkusvill-html-zakas-order/)

## Что это

Одна HTML-страница, которая позволяет:

1. Продиктовать заказ на естественном языке (распознавание речи происходит на клавиатуре смартфона) - продукты соберутся в корзину автоматически или выбрать продукты из списка (119 товаров в 12 категориях) вручную
3. Нажать «Собрать корзину» → генерируется прямая ссылка на корзину ВкусВилл
4. Уже на сейте ВкусВилл скорректировать количество и оплатить (возможность доставки по вашему адресу ВкусВилл проверяет сам)

Всё работает в браузере телефона или ПК. **Сервер не нужен** — селектор вызывает MCP API ВкусВилл напрямую из браузера.

## Возможности

### 🎯 Быстрый ввод
Введи `нарзан йогурт мандарин` в строку поиска — трёхэтапный JS-матчинг сам найдёт товары:

1. **Alias-матчер** — 106 алиасов из quick-order
2. **Substring-поиск** — по всем 119 названиям
3. **Word + bigram** — токены склеиваются для многословных названий

### 📱 PWA
- Установка на домашний экран (Android Chrome, iPhone Safari)
- Иконка 🛒
- **Офлайн-каталог** — Service Worker кэширует страницу, всё работает без интернета (кроме создания корзины — нужен MCP)

### 🗂️ Дерево категорий
12 категорий с раскрытием/сворачиванием. Изначально все свёрнуты. При вводе в поиск — дерево скрывается, показывается панель быстрого матча.

### 🎨 UI
- Тёмная тема
- Адаптивная вёрстка (max-width 600px)
- Копирование ссылки в буфер
- Enter → фокус на кнопку «Собрать корзину»

## Серверная часть (опционально)

Flask-сервер для случаев, когда нужен прокси к MCP:

| Метод | Путь | Описание |
|---|---|---|
| GET | `/` | HTML-фронтенд |
| GET | `/health` | `{"ok":true}` |
| POST | `/api/resolve` | items → матчинг → корзина |
| POST | `/api/match` | Локальный матчинг одного запроса |
| POST | `/api/cart` | Корзина по xml_id |

### Деплой

См. [DEPLOY.md](DEPLOY.md) — пошаговая инструкция.

Кратко:

```bash
pip install -r requirements.txt
cp vkusvill-cart.service /etc/systemd/system/
systemctl enable --now vkusvill-cart
```

Стек: Python 3.12, Flask, Gunicorn, Nginx, Let's Encrypt, systemd.

## Структура проекта

```
vkusvill-selector.html    # Основной HTML5-селектор (автономный, открывается в браузере)
sw.js                     # Service Worker (PWA офлайн)
manifest.json             # PWA manifest
app.py                    # Flask-сервер
mcp_client.py             # MCP-клиент для API ВкусВилл
requirements.txt          # Python-зависимости

skills/
  vkusvill-quick-order/   # Alias-матчер (52 товара, мгновенный)
  vkusvill-smart-cart/    # Трёхэтапный матчинг (substring → Левенштейн → триграммы)

vkusvill-cart.service     # systemd unit
healthcheck.sh            # Health check (systemd timer)
categories.json           # Категории товаров
vkusvill_prefs.json       # Товары (50 позиций)
```

> Список моих часто заказываемых товаров — в приложенном файле `История покупок.html`.

>
> Что должно получиться:
> - Тёмная тема, адаптивная вёрстка (max-width 600px), PWA-манифест
> - Дерево категорий с поиском (как в исходном репо)
> - Быстрый ввод: строка принимает текст без запятых («нарзан йогурт мандарин»), трёхэтапный JS-матчинг (alias → substring → word + bigram)
> - Кнопка «Собрать корзину» → прямой JSON-RPC вызов `mcp001.vkusvill.ru/mcp` → ссылка на корзину
> - Service Worker для офлайн-каталога
> - Кнопка копирования ссылки в буфер

**Как сохранить историю покупок:**

1. Зайдите на [vkusvill.ru/goods/set-istoriya-pokupok/](https://vkusvill.ru/goods/set-istoriya-pokupok/) (нужен логин)
2. Пролистайте до конца, чтобы подгрузились все товары
3. Сохраните страницу: **Файл → Сохранить как** (Ctrl+S / Cmd+S)
4. Тип файла: **«Веб-страница, полностью»**
5. Полученный HTML-файл приложите к промту выше

AI сам распарсит историю покупок, найдёт xml_id товаров через MCP API ВкусВилл, сгруппирует по категориям и соберёт готовый `vkusvill-selector.html` под ваш список.
